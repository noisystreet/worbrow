# ADR-001：程序形态 = 单任务 CLI

- 状态：已接受
- 日期：2026-07-31

## 背景

工具面向 AI agent 提供"搜索引擎搜索"能力。调用方（agent）可能是任意语言/框架，
需要进程隔离与稳定的机器可读契约。

## 决策

- 形态为**单任务 CLI**：agent 以子进程方式调用，每次执行一次搜索任务
- 预留 `--connect <cdp-endpoint>`（连接已运行的浏览器）作为性能演进，不改变主体契约

## 后果

- **得到**：进程隔离天然防泄漏；与语言无关，任何 agent 框架可用子进程调用；部署零依赖
  （单二进制 + 本机浏览器）
- **付出**：每次任务有浏览器冷启动开销（~0.8s）；无法跨任务复用 cookie/会话
- **拒绝**：HTTP 常驻服务（运维面大，且当前只有单一消费者）；库内嵌（agent 未必是 Rust，
  且进程隔离优势消失）
