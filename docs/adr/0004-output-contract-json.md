# ADR-004：输出契约 = JSON schema v1 + 语义化退出码

- 状态：已接受
- 日期：2026-07-31

## 背景

agent 以子进程方式调用工具，需要长期稳定的机器可读契约。

## 决策

- stdout 仅输出 JSON（成功包/失败包），schema 版本化（顶层 `schema_version`）
- 退出码语义化：0 成功 / 2 参数错 / 3 环境错 / 4 搜索失败 / 124 超时 / 1 内部错
- 字段**只增不改**；破坏性变更 bump schema 主版本（agent 端显式校验并告警）
- 日志一律 stderr，不污染 stdout 管道

## 后果

- **得到**：agent 端解析逻辑可长期冻结；错误可机器区分（验证码 / 引擎故障 / 超时 / 环境问题）
- **付出**：schema 一旦发布即成契约，演进需走版本策略（见 design.md §7.1）
- **拒绝**：Markdown 输出作为主契约（人读可，机器不可靠）；结构化日志替代 stdout JSON
  （破坏管道语义）
